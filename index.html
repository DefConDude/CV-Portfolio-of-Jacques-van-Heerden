My Flagship AI Project

FNB Commercial Credit Review Agent

Mint Group · 2026

A multi-agentic solution that reviews commercial credit requests of R100M - R600M, turning manual review effort into deterministic, auditable analysis.

  • Deterministic math runs in a Python agent on OpenShift, so figures are calculated and reproducible rather than generated.
  • An orchestration agent coordinates a report sub-agent that explains risk in natural language using OpenAI LLMs.
  • PostgreSQL and Langfuse hold state and observability; Weaviate powers vector search over supporting documents.
  • Output is written into a Word template and saved to SharePoint for the credit committee.
